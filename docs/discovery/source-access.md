## Permission gate and current sample workflow

1. Record each source URL, inspection/acquisition time, response/policy evidence and allowed acquisition method. Establish storage, excerpt display, embedding/external processing, redistribution and hosted-use rights separately. Unknown permission is not allowed-by-default; do not contact university staff automatically on the owner's behalf.
2. Honor the observed blanket robots restriction on the syllabus host. Prefer an authorized university structured export; otherwise use a permitted official PDF export or operator-acquired public sample consistent with applicable terms. Never bypass login/CAPTCHA/access controls, enumerate guessed IDs or use a supplied file to erase restrictions. No authenticated content or session-cookie retention.
3. Obtain 3–5 representative course pages or equivalent export sections for the Informatics-target AY2026 second-semester scope, retaining original URL, document/page ID where available, year evidence, fetched time, optional source-update time, encoding and byte hash. Keep original bytes local/outside Git unless redistribution is allowed. Cover explicit exams, explicit exam absence and unknown assessment where actually available; do not fabricate a missing class or impose a classification table. Locate a relevant official handbook separately; absent handbook coverage does not block basic sample discovery.
4. Human-check Japanese encoding, headings/table order, all meetings and original assessment text against labels. Decode declared Windows-31J as CP932 where applicable; current detail-page encoding still needs verification. Choose HTML/PDF adapter from observed layout; preserved PDF citations need printed and file-page indexes. Reproducible extraction on a small sample precedes larger collection.
5. If access is later permitted, proposed starting traffic ceiling is concurrency **1**, at least **5 seconds** between requests, conditional requests where supported and exponential backoff. Stop on 401/403/429 or changed robots/terms. No university rate limit was established; stricter source conditions override this proposal. Limit collection to the approved Informatics target scope; preconfigured other affiliations do not authorize broader acquisition.

Refresh publication, revision invalidation and source identity use [design §4](../technical-design.md#4-academic-data-and-source-artifacts); they do not grant access permission. Synthetic artifacts support engineering checks but cannot prove real-source feasibility or recommendation quality. Validate sample extraction before expanding to the full target collection; the first end-to-end flow needs only the permitted sample.

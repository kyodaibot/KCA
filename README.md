# course-bot

面向京都大学学生的选课推荐 chatbot。

## 目录结构
- backend/   后端 API（FastAPI）
- rag/  数据抓取与向量化
- frontend/  前端
- docs/      技术说明

## 本地启动
（第 2 步完成后补充：docker compose up）

## 协作约定
- 不直接推送到 main，从 main 切分支开发，通过 PR 合并
- 分支命名：feature/xxx、fix/xxx、infra/xxx
- PR 保持小而聚焦，至少一位同学 review 后合并
- 合并方式：Squash merge
- 密钥不进仓库，见 .env.example
